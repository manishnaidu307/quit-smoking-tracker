# Quit Smoking Tracker 🚭

A responsive habit-tracking web application designed to support smoking cessation through structured urge control, progress tracking, and positive reinforcement.

## ✨ Features
- One-tap urge control with guided 60-second countdown
- Daily and lifetime urge tracking
- Streak tracking with manual reset
- Reward badges based on progress milestones
- Money-saved calculation
- Light and dark mode with persistent theme preference
- Fully responsive, mobile-first UI
- Persistent data storage using browser `localStorage`

## 🛠 Tech Stack
- **HTML5** — semantic structure  
- **CSS3** — responsive layout, dark mode theming  
- **JavaScript (Vanilla)** — state management, timers, events  
- **localStorage** — client-side persistence  

## 🧩 Application Highlights
- Clean, modular JavaScript architecture with refactored functions
- User-centric UI designed for clarity during high-stress interactions
- Gamification via rewards and badges to reinforce positive behavior
- No external libraries or frameworks
