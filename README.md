# Quit Smoking Tracker 🚭

A simple web application built to help quit smoking by tracking urges, maintaining streaks, and visualizing progress.

## Features
- One-tap urge control with 60-second countdown
- Daily and lifetime urge tracking
- Streak system with manual reset
- Money saved calculator
- Data persistence using browser localStorage

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)

## Why I Built This
This project was built to solve a real problem while learning core web development concepts such as state management, event handling, and data persistence.
